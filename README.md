# AI Content Hub

Website Next.js App Router + TypeScript + Tailwind CSS cho dự án AI Content Hub.

## Cài đặt

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Build production

```bash
npm run build
npm run start
```

## Cấu trúc dữ liệu

- `data/tools.ts`: dữ liệu thư viện công cụ AI.
- `data/blogPosts.ts`: dữ liệu bài viết mẫu.
